About Me

I am a Ph.D. candidate in Computer Science at Northeastern University. My research focuses on advancing Automated Software Engineering through AI-assisted and agentic techniques that analyze, test, transform, and improve software systems. My work combines program analysis, software testing, empirical evaluation, and large language models to automate software engineering tasks while preserving software correctness and reliability.

Research Interests

Artificial Intelligence for Software Engineering (AI4SE) · Automated Software Engineering · Software Testing · Program Analysis · Program Transformation · Empirical Software Engineering
