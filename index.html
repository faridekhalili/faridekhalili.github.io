About Me

My research focuses on Automated Software Engineering, developing techniques to automatically analyze, test, transform, repair, and optimize software systems. I combine program analysis, software testing, and empirical evaluation with emerging AI techniques, particularly large language models (LLMs) and agentic systems, toward a broader vision of AI-powered automated software evolution. My goal is to improve software quality, reliability, and performance while preserving intended behavior.

Research Interests

Artificial Intelligence for Software Engineering (AI4SE) · Automated Software Engineering · Software Testing · Program Analysis · Program Transformation · Empirical Software Engineering
